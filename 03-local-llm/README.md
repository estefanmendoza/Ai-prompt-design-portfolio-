# Local LLM & Agent Workflow Experiments

**Tools:** Ollama · Qwen3 8B · StarNet

## Overview

Exploration of local language-model setup, model responsiveness, prompt structuring, and role-based agent workflows using an Intel-based Mac.

## What I explored

- Running Qwen3 8B through Ollama
- Comparing local-model responsiveness with hosted AI assistants in practical workflows
- Structuring reusable prompts for ecommerce research and content review
- Designing multi-agent roles for research, product decisions, and oversight in StarNet

## Key learning

Model selection should match the task and available computing resources. Local inference can introduce substantial latency, so workflow design must balance quality, speed, and the need for human review.
