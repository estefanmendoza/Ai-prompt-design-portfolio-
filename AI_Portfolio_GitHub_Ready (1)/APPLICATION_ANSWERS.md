## Describe one prompt or conversation flow you built yourself. What was broken about the first version, and how did you find out?

While building SANCTVM in Base44, I used prompts to turn a clothing-brand concept into an ecommerce website. My first instructions were too broad: the site was usable as a starting point, but the visual hierarchy, branding and customer journey felt generic rather than intentional. I discovered this by reviewing the actual live pages and interactions against what I wanted—not just the AI's description of what it built. I rewrote my prompts with specific layout, tone, navigation and functional requirements, then checked the outputs again. I also learned not to confuse a working interface with a verified backend when a security scan surfaced issues in generated code.

**Scope note:** This describes iterative user-led work on SANCTVM, not an independently engineered healthcare voice agent or a claim that security flaws were remediated.
