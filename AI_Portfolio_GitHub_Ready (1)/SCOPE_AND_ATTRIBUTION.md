# Scope, authorship & transparency

This public portfolio intentionally distinguishes completed personal work from demonstration material.

- **SANCTVM** was built through hands-on AI-assisted website development and prompt iteration. The case study is a retrospective based on that work; sample prompts have been reconstructed to explain a workflow rather than presented as exact archived prompt logs.
- **Senior check-in** is an **independent concept**. The Python code and scenario set were created with AI coding assistance for portfolio demonstration and should be reviewed, understood, and adapted before being represented as personal programming proficiency. It is not production software, not an LLM-powered voice agent, not a medical device, and has not been tested with real people or private recordings.
- **Local LLM experiments** cover practical use of Ollama/Qwen3 and exploration of StarNet. They are not claims of production systems, statistical benchmarks, or fully autonomous commerce tools.
- **No fabricated metrics:** Sample transcripts and test inputs are synthetic. Automated checks demonstrate repeatable behavior of this offline demo only; they do not establish model accuracy, fairness, safety, or real-world effectiveness.
- **No confidential data:** There are no API credentials, customer transcripts, personal healthcare records, or proprietary Sensi.AI materials in this repository.

This portfolio is intended to show design reasoning, build curiosity, learning velocity, and the ability to explain tradeoffs clearly.
