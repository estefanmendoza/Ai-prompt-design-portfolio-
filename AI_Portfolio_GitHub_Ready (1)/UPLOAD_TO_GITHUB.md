# Publish this portfolio to GitHub

This folder is **not yet a live GitHub repository**. The final application URL will exist after publishing it to your own GitHub account.

## Browser path (no Terminal needed)

1. Sign in to GitHub and create a **public** repository named `ai-prompt-design-portfolio` (or another available name).
2. Select **Add file → Upload files**.
3. Unzip the downloadable portfolio package. Drag the **contents** of the `estefan-ai-prompt-design-portfolio` folder (including all project subfolders) into the upload area.
4. Review the file list and choose **Commit changes**.
5. Open the repository to confirm that the main README displays and the project folder links work.
6. Your GitHub field will be the URL GitHub shows, typically `https://github.com/YOUR_USERNAME/ai-prompt-design-portfolio`. **Replace YOUR_USERNAME with your actual account name. Do not paste the example address as though it were live.**

Avoid uploading personal documents containing your phone number, private APIs, keys, payment or customer data. The included work-sample PDF is a concept sample, not a proprietary record.

## Quality check before publishing

- Read the SANCTVM claims and adjust any detail that does not match your actual experience.
- Run the test commands in README; be prepared to explain the Python demo's simple decisions and limitations.
- Keep the scope/attribution document; do not portray the simulation as a production voice agent.
- Link only to projects you are comfortable discussing in an interview.
